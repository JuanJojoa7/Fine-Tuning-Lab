## Descripción
Este proyecto corresponde a una práctica académica enfocada en **Fine-Tuning** (ajuste fino de modelos de lenguaje).  
El objetivo principal fue **personalizar un modelo preentrenado** a través de ejemplos específicos, para mejorar su rendimiento en un dominio particular y observar cómo cambia su capacidad de respuesta.  

---

## Pasos Realizados

1. **Preparación del Dataset**  
   - Se definieron y organizaron ejemplos en formato adecuado.  
   - El dataset fue limpiado y convertido en la estructura requerida (JSONL/CSV).  

2. **Entrenamiento (Fine-Tuning)**  
   - Se utilizó un modelo base para aplicar el ajuste fino.  
   - Se ejecutó el entrenamiento con los ejemplos definidos, monitoreando métricas de aprendizaje.  

3. **Validación de Resultados**  
   - Se probó el modelo ajustado con ejemplos nuevos.  
   - Se comparó el desempeño frente al modelo base para verificar la mejora.  

---

## Resultados
- El modelo ajustado mostró un mejor entendimiento en las tareas específicas de la práctica.  
- Se comprobó que, con ejemplos bien estructurados, el modelo aprende patrones de respuesta más coherentes.  

---

## Conclusiones
- El **Fine-Tuning** es una técnica poderosa para especializar modelos de lenguaje en un dominio concreto.  
- La calidad del dataset es fundamental: datos mal estructurados generan un mal rendimiento.  
- El proceso permitió entender las fases clave: **preparación de datos, entrenamiento y validación**.
